API Documentation

Authentication

All API requests require an API key to be included in the header:

X-API-Key: your_api_key_here

Endpoints

Start a Scan

POST /api/scan

Request body:

{
    "url": "https://example.com",
    "scan_type": "basic",
    "timeout": 30,
    "attack_options": {
        "xss": true,
        "sqli": true,
        "ports": false,
        "paths": true
    }
}

Get Scan Results

GET /api/results/{scan_id}

List API Keys

GET /api/keys

Generate API Key

POST /api/keys

Request body:

{
    "name": "Key Name"
}

Revoke API Key

DELETE /api/keys/{key}
