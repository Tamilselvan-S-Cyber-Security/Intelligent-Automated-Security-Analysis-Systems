Using API Keys

Web Interface:

To use an API key in the web interface, select "API Enhanced Scan" on the scanner page and enter your API key in the field that appears.

Command Line Interface:

To use an API key with the CLI tool, you can either:

  • Select "API Enhanced Scan" from the menu and enter your key when prompted
  • Use the command-line argument: 
    python cyberwolf.py --url https://example.com --api-key YOUR_API_KEY

API Access:

For programmatic access, include your API key in the request headers:


curl -X POST https://cyberwolf.example.com/api/scan \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"url": "https://example.com"}'
