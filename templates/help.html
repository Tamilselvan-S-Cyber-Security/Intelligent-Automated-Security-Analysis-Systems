CyberWolf Scanner Help & Documentation

CyberWolf is an advanced vulnerability scanner designed to help you identify security weaknesses in web applications.

Getting Started

To start using CyberWolf to scan for vulnerabilities, follow these simple steps:

  1. Navigate to the Scanner page.
  2. Enter the target URL you wish to scan (e.g., https://example.com).
  3. Choose the scan type (Basic or API Enhanced).
  4. Click the "Start Scan" button to begin the vulnerability assessment.
  5. View the results and follow the remediation recommendations.
Important: Only scan websites that you own or have explicit permission to test. Unauthorized scanning may be illegal in some jurisdictions.

Scan Types

CyberWolf offers two types of vulnerability scans:

Basic Scan

The Basic Scan performs standard checks for common vulnerabilities such as XSS, SQL Injection, open ports, and vulnerable paths. This scan is suitable for most routine security assessments.

  • No API key required
  • Detects common vulnerabilities
  • Faster completion time
API Enhanced Scan

The API Enhanced Scan leverages advanced security APIs to perform a more thorough assessment. This scan type can detect a wider range of vulnerabilities and provides more detailed information.

  • Requires API key
  • Deeper vulnerability detection
  • More comprehensive results
  • May take longer to complete

Vulnerability Types

CyberWolf scans for the following types of vulnerabilities:

Cross-Site Scripting vulnerabilities allow attackers to inject malicious scripts into web pages viewed by other users. These scripts can steal cookies, session tokens, or other sensitive information.

Common XSS Types:
  • Reflected XSS: Malicious script is reflected off a web server, such as in search results or error messages.
  • Stored XSS: Malicious script is stored on the target server, such as in a database, message forum, or comment field.
  • DOM-based XSS: Vulnerability exists in client-side code rather than server-side code.

SQL Injection vulnerabilities allow attackers to interfere with database queries made by an application. Attackers can potentially view, modify, or delete database data, or execute administrative operations.

Common SQL Injection Types:
  • Error-based: Forces the database to generate an error that reveals information about the database structure.
  • Union-based: Uses UNION SQL operator to combine results from multiple SELECT statements.
  • Boolean-based: Uses true/false questions to extract information from the database.
  • Time-based: Uses time delays to determine if a condition is true or false.

Open ports on a server can potentially expose services that attackers can exploit. CyberWolf scans for open ports and identifies the services running on them.

Common Risks:
  • Unnecessary Services: Services that are not required for the application to function but are still running.
  • Outdated Services: Services with known vulnerabilities that have not been patched.
  • Misconfigured Services: Services that are not properly secured, such as lacking authentication.

Vulnerable paths and directories can expose sensitive files or provide information about the web application's structure that attackers can use to exploit other vulnerabilities.

Common Issues:
  • Directory Listing: Server configured to show the contents of directories.
  • Sensitive Files: Configuration files, backup files, or source code files that are accessible.
  • Default Directories: Default installation directories that contain sensitive information.
  • Administrative Interfaces: Admin panels or interfaces that are not properly secured.

Interpreting Results

After a scan is completed, CyberWolf provides a comprehensive report of the vulnerabilities found. Here's how to interpret the results:

Risk Levels:
  • High: Critical vulnerabilities that could lead to system compromise, data theft, or significant service disruption. These should be addressed immediately.
  • Medium: Important vulnerabilities that pose a significant risk but may require specific conditions to be exploited. These should be addressed in a timely manner.
  • Low: Minor vulnerabilities that pose minimal risk on their own but could be combined with other vulnerabilities to pose a greater threat. These should be addressed as part of routine maintenance.

The report also includes detailed information about each vulnerability, including location, affected parameters, payloads used, and specific recommendations for remediation.

Tip: Always prioritize vulnerabilities based on risk level and the sensitivity of the affected system or data.

API Enhanced Scanning

API Enhanced Scanning provides more comprehensive vulnerability detection by leveraging advanced security APIs. To use this feature, you'll need an API key.

Benefits of API Enhanced Scanning:
  • Detection of more complex and subtle vulnerabilities
  • Advanced payload testing for better accuracy
  • Reduced false positives
  • More detailed vulnerability information

CLI Usage

CyberWolf also provides a command-line interface (CLI) for users who prefer terminal-based operations or need to integrate vulnerability scanning into scripts or automation. 

$ python cyberwolf.py --help
Basic Commands:
Command Description
python cyberwolf.py Start the CyberWolf CLI with interactive menu
python cyberwolf.py --url [URL] Scan the specified URL with basic scan
python cyberwolf.py --url [URL] --api-key [KEY] Scan the specified URL with API enhanced scan
python cyberwolf.py --url [URL] --output [FILE] Save scan results to specified file
Additional Options:
  • --timeout [SECONDS] - Set request timeout
  • --verbose - Enable verbose output
  • --no-ports - Skip port scanning
  • --no-paths - Skip path scanning
  • --no-xss - Skip XSS scanning
  • --no-sqli - Skip SQL Injection scanning

Frequently Asked Questions

You should only scan websites that you own or have explicit permission to test. Unauthorized scanning may be illegal in some jurisdictions and could violate computer misuse laws. Always obtain proper authorization before scanning any website.

Scan duration depends on several factors, including the size of the website, the number of pages and forms to test, network latency, and the selected scan type. Basic scans typically complete in a few minutes, while API Enhanced scans may take longer due to the more thorough testing performed.

The current version of CyberWolf scans publicly accessible pages and does not support authenticated scanning. Future versions may include support for authenticated scanning with session handling capabilities.

CyberWolf focuses on common web vulnerabilities such as XSS, SQL Injection, open ports, and vulnerable paths. While the scanner is effective at identifying these issues, a comprehensive security assessment should also include manual testing, code reviews, and other specialized security tests. CyberWolf is a valuable tool in your security toolkit, but should not be the only one used.

If vulnerabilities are found in your own website, follow the remediation recommendations provided in the scan report. If you discover vulnerabilities in a third-party website (that you had permission to scan), responsibly disclose the issues to the website owner or their security team. Many organizations have a responsible disclosure policy or bug bounty program that outlines the process for reporting security issues.
